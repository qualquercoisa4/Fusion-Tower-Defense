# Fusion TD

Protótipo inicial de um jogo tower defense com interface sci-fi industrial, inspirado nas referências visuais fornecidas.

## Estado atual

- Menu principal responsivo com o título **FUSION TD**.
- Identidade visual em azul elétrico, circuitos, núcleo de energia e painéis metálicos.
- Botões **Loja**, **Jogar** e **Torres** com janelas de protótipo.
- Implementado em HTML, CSS e JavaScript puro; sem dependências ou etapa de build.

## Executar localmente

Abra `index.html` em um navegador.

## Publicar

O repositório pode ser importado como projeto estático na Vercel. Não é necessário comando de build; defina `index.html` como página inicial e deixe o campo de build vazio.
